# Loving you

A romantic lyric visual — single self-contained HTML file with embedded audio. Open `index.html` in any browser and tap the heart.

## How to use
- Download `index.html`
- Open it in any browser (phone / tablet / laptop / PC)
- Tap the pulsing heart to play

The audio (the song) is embedded directly inside the HTML — no internet required, no extra files needed.
